- **コーポレートサイト（leam.co.jp / `leam-hp`）とは意図的に切り離してある。**
  広告が止まったときにコーポレート資産へ被害が波及しないようにするため（2026-09-08 方針）

- **正ソースは `/Users/wing/Claude Code/leam-tts-lp/`。** ここはデプロイ用のコピー

## 広告審査で落とさないための決めごと

代理店（SOIL・秋山さん）の2026-08-31の指摘を反映済み：

| 指摘 | 対応 |
|---|---|
| 実績金額の主訴求（「月売上◯◯万円」）はMetaの収益機会系ポリシーで最も厳しく見られる | 個別事例の売上金額を載せない |
| `tiktok.leam.co.jp` のように第三者ブランド名をサブドメインに含めるとなりすまし判定リスク | `leam-tts.jp` にした |
| 「ByteDance社公認パートナー企業と連携」は第三者認定の示唆 | 記載しない |

加えて **補助金・助成金は一切書かない**（過去BANの主因と見立てられているため）。
